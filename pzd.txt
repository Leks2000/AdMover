Общая идея
Create a complete 3D browser game using Three.js, WebGL, TypeScript and Vite.

The game should look like a modern hyper-casual mobile game.

Genre:
Crowd Runner + Zombie Survival + Mob Control.

Theme:
The player commands a growing army of soldiers fighting endless waves of zombies.

Platform:
WebGL browser game.
Desktop and mobile compatible.
Optimized for mobile devices.
Визуальный стиль
Visual Style:

- Full 3D graphics.
- Built with Three.js and WebGL.
- Bright colorful hyper-casual visuals.
- Low-poly art style.
- Clean mobile game aesthetics.
- Soft shadows.
- Dynamic lighting.
- Cartoon-style characters.
- Stylized explosions.
- Floating damage numbers.
- Smooth animations.
- Particle effects.
- Muzzle flashes.
- Coin collection effects.
- Camera shake during explosions.
- Mobile game quality similar to:
  Count Masters,
  Mob Control,
  Survivor.io,
  Last War Survival.
Игрок
Player:

- A commander leading a group of soldiers.
- Automatic forward movement.
- Left and right movement using mouse drag or touch swipe.
- Crowd follows the leader.
- Crowd count displayed above the army.
- Soldiers automatically shoot nearby enemies.

Производительность

Чтобы не сделал 2000 объектов и не умер FPS.

Performance Requirements:

Use object pooling.

Use InstancedMesh for soldiers.

Use InstancedMesh for zombies.

Target:
60 FPS on mobile devices.

Support:
1000+ soldiers
1000+ zombies

Avoid creating and destroying objects every frame.
